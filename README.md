**NutraMetrics** — это End-to-End аналитический продукт на живых данных аптечного рынка РФ (**897 пероральных препаратов** в 9 категориях с кросс-агрегаторным покрытием `Uteka.ru`, `Apteka.ru`, `Zdravcity.ru`, `Eapteka.ru`, `Ригла`, `Планета Здоровья`), объединяющий **глубокую доменную экспертизу в R&D нутрицевтиков и фармацевтике** с **коммерческой и продуктовой аналитикой данных**.

> **О бэкграунде автора (Бурляев Д.В.):**  
> Химик-исследователь (R&D) и аналитик данных с 6+ летним опытом разработки систем доставки биологически активных веществ в FoodTech/Nutraceutical-стартапе **«Nuversys» (Израиль)** (технологии микроинкапсуляции жирорастворимых витаминов D, E, A, K, Омега-3 и куркумина для внедрения в жевательные пастилки *Gummies*, протеиновые батончики и функциональные продукты) и разработки твердых лекарственных форм в **«Биннофарм Групп»**.

## 🎯 Бизнес-задача: зачем рынку нужен NutraMetrics?

На рынке БАДов и витаминов РФ существует фундаментальная асимметрия информации:
1. **Для потребителя:** Сравнение «цены за упаковку» или «цены за 1 таблетку» вводит в заблуждение. Дешевая банка оксида магния за 400 ₽ с приемом по 4 таблетки в день (курс 7.5 дней, биодоступность ~4–10%) в пересчете на усвоенную суточную дозу оказывается **дороже**, чем банка хелатного бисглицината или мицеллированной формы за 700 ₽ на 60 дней. Кроме того, производители нередко используют маркетинговые уловки в рекламном описании (называя обычный цитрат магния «хелатной формой»).
2. **Для бизнеса (Category Managers аптек/маркетплейсов и R&D-директоров):** Необходимо понимать, какие бренды берут справедливую премию за сложную технологию доставки (`Уровень 3: Липосомы / Мицеллы / Хелаты / Коферменты`), какие продают базовые неорганические соли со 100–200% маркетинговой наценкой, и в каких пересечениях `Категория витамина × Форма выпуска` находятся **свободные рыночные ниши («Голубые океаны»)** для запуска новых высокомаржинальных SKU.

## 🧪 Кастомная система метрик (R&D + Unit Economics)

### 1. Обычная цена 1 дня приема ($C_{\text{day}}$) и Цена дня с учетом усвоения ($\text{BAP-Dose}$)

1. **Обычная номинальная стоимость 1 дня приема ($C_{\text{day}}$, ₽/день):**
   $$C_{\text{day}} = \frac{\text{Цена упаковки}}{\text{Количество порций в упаковке} / \text{Порций в день}}$$

2. **Коэффициент усвояемости и технологии доставки ($K_{\text{усвоения}}$ — строгая классификация по графе «Состав»):**
   > **Важное R&D-правило:** Классификатор анализирует **только официальную графу «Состав» (`composition_text`), наименование и активное вещество**, полностью исключая рекламное описание (`description_text`), чтобы маркетинговые заявления не завышали уровень препарата.
   - **`Уровень 1: Базовая неорганическая форма` ($K_{\text{усвоения}} = 1.00$, 188 препаратов):** Неорганические соли минералов (оксиды, сульфаты, карбонаты, хлориды), синтетическая фолиевая кислота / цианокобаламин в простых таблетках, классические сахарные драже (*Ревит, Ундевит, Гексавит*).
   - **`Уровень 2: Органическая / Улучшенная форма` ($K_{\text{усвоения}} = 1.35$, 495 препаратов):** Органические соли минералов (цитраты, малаты, лактаты, глюконаты, пиколинаты, фумараты), мягкие желатиновые капсулы (*Softgels*), жидкие масляные капли, шипучие таблетки (*Effervescent*), жевательные мармеладные пастилки (*Gummies*), гидролизованные пептиды коллагена.
   - **`Уровень 3: Продвинутая R&D-форма` ($K_{\text{усвоения}} = 1.75$, 214 препаратов):** Аминокислотные хелатные комплексы (**бисглицинат, таурат, L-треонат**), **липосомальные**, **мицеллированные**, **микроинкапсулированные / сукросомальные** матрицы (*Lipofer, SiderAL, NovaSOL, Аквадетрим*), коферментные активные формы витаминов (**L-метилфолат, метилкобаламин, P-5-P**), куркумин с биоэнхансером **пиперином (BioPerine)**, высококонцентрированная триглицеридная **rTG Омега-3 (60–90%)**, трипептиды морского коллагена и синергические матрицы **D3 + K2 (MK-7)**.

3. **Коэффициент чистоты вспомогательного состава Clean Label ($K_{\text{чистоты}} \in [0.85, 1.15]$):**
   - **Штрафы:** за сахар / глюкозно-паточный сироп на первых местах состава (`-0.08`), белый пигмент **диоксид титана `E171`** в оболочках таблеток и капсул (`-0.07`), синтетические азокрасители и жесткие консерванты (`-0.05`).
   - **Бонусы:** за чистые носители (МСТ-масло среднецепочечных триглицеридов, оливковое масло Extra Virgin, растительные капсулы ГПМЦ/пуллулан, пребиотик инулин) и короткий перечень эксципиентов без `E171` и сахара (`+0.08..+0.12`).

4. **Реальная стоимость суточной дозы с учетом усвоения и чистоты (`BAP-Dose`, ₽/день):**
   $$\text{BAP-Dose} = \frac{C_{\text{day}}}{K_{\text{усвоения}} \times K_{\text{чистоты}} \times D_{\text{дозы}}}$$
   где $D_{\text{дозы}} = \text{clip}\left(\sqrt{\frac{\text{Суточная дозировка вещества}}{\text{Рекомендуемая норма категории}}}, 0.55, 1.75\right)$ учитывает полноту профилактической дозировки активного вещества.

5. **Индекс ценности нутрицевтика (`NVI`, 0–100 баллов):**
   $$\text{NVI} = 0.45 \cdot S_{\text{выгода}} + 0.30 \cdot S_{\text{усвоение}} + 0.15 \cdot S_{\text{чистота}} + 0.10 \cdot S_{\text{отзывы}}$$
   Агрегирует реальную ценовую выгоду дня курса `BAP-Dose` (45%), технологический уровень усвоения формы $K_{\text{усвоения}}$ (30%), чистоту состава без `E171` и сахара $K_{\text{чистоты}}$ (15%) и подтвержденный рейтинг покупателей в аптеках (10%).

### 2. Честная цена по составу и Переплата / Выгода за бренд — `Brand Overpay %` (Hedonic Pricing ML + SHAP)

Мы обучаем регрессионную модель гедонистического ценообразования (`CatBoostRegressor` на $\ln(\text{Price})$, **$R^2 = 0.568$** на кросс-валидации), используя **только объективные R&D и галеновые характеристики препарата** (категория витамина, длительность курса, полнота суточной дозировки, объем упаковки, уровень усвоения `Уровень 1–3`, форма выпуска, чистота состава `Clean Label`, страна происхождения) **без участия имени бренда**:
$$\text{Переплата / Выгода за бренд (\%)} = \frac{P_{\text{аптека}} - P_{\text{честная}}}{P_{\text{честная}}} \times 100\%$$
- Точная аддитивная декомпозиция `SHAP Values` переводится в рубли (`shap_base_rub`, `shap_category_rub`, `shap_dosage_course_rub`, `shap_bio_tier_rub`, `shap_delivery_form_rub`, `shap_clean_label_rub`, `shap_origin_rub`), формируя понятный водопадный график (**SHAP Waterfall Chart**) для каждого из 897 препаратов и для интерактивного R&D-симулятора запуска нового БАДа.

## 📊 Проверка 5 статистических гипотез (`scipy.stats`, `statsmodels`)

На очищенной выборке из **897 пероральных нутрицевтиков** проверены 5 продуктовых и химико-технологических гипотез с явной формулировкой нулевой ($H_0$) и альтернативной ($H_1$) гипотез (полный код, графики и таблицы — в `notebooks/eda_and_hypotheses.ipynb` и на Вкладке №5 дашборда):

| Код | Проверяемый вопрос ($H_0$ vs $H_1$) | Статистический критерий | Статистика и p-value | Главный инсайт и практическая выгода |
| :--- | :--- | :--- | :--- | :--- |
| **H1** | **Правда ли, что современные хелатные и липосомальные витамины (Уровень 3) обходятся дороже обычных?** | `Kruskal-Wallis H` + попарный `Mann-Whitney U` (поправка Холма–Бонферрони) | $H_{\text{NVI}} = 206.65$<br>$p = 1.34 \times 10^{-45}$<br>$\varepsilon^2 = 0.2306$ | **Миф развенчан:** номинально день приема `Уровня 3` дороже `Уровня 1` (**17.23 ₽** vs **10.30 ₽**), но за счет высокой биодоступности ($1.75\times$) и полноценных дозировок **реальная цена усвоенной дозы у `Уровня 3` самая низкая на рынке — 9.21 ₽/день** (против **14.37 ₽** у `Уровня 2` и **10.13 ₽** у `Уровня 1`), а средний `NVI` достигает **73.7** против **45.6**. |
| **H2** | **Стоит ли переплачивать в 2 раза за импортные витамины при одинаковом составе?** | Двухфакторный `Type-II OLS ANOVA` + `Mann-Whitney U` | $F = 265.37$<br>$p = 2.22 \times 10^{-52}$<br>$r_{rb} = 0.5223$ | **Подтверждено:** даже при абсолютно одинаковом уровне химической формы (`Уровень 1–3`) и категории витамина импортная упаковка стоит в 2.2 раза дороже (**1065 ₽** vs **486 ₽** у РФ, чистая наценка **+133.4%**). Российские R&D-бренды Уровня 3 выигрывают по среднему индексу ценности `NVI` (**63.6** vs **44.9**). |
| **H3** | **Как форма выпуска (мармеладные пастилки `Gummies` и `Липосомы`) влияет на цену курса и состав?** | `Kruskal-Wallis H` + `Mann-Whitney U` + Bootstrap 95% ДИ медианы | $H = 24.28$<br>$p = 2.18 \times 10^{-5}$ | **Подтверждено:** липосомальные/мицеллированные формы формируют премиум-сегмент (**33.20 ₽/день**), а пастилки `Gummies` обходятся доступно (**11.16 ₽/день** vs **12.97 ₽/день** у твердых таблеток) и получают лучшие оценки покупателей (**4.39 ⭐**), но в **62.1%** случаев состоят из сахара и патоки — прямая R&D-ниша для бессахарных `Gummies`. |
| **H4** | **В каких именно препаратах чаще всего скрывается спорный белый краситель диоксид титана (`E171`)?** | Критерий согласия Пирсона ($\chi^2$) + $V$ Крамера | $\chi^2_{\text{E171}} = 82.25$ ($p = 4.79 \times 10^{-15}$, $V = 0.3028$)<br>$\chi^2_{\text{Sugar}} = 253.02$ ($p = 6.30 \times 10^{-51}$, $V = 0.5311$) | **Подтверждено:** запрещенный в ЕС пищевой краситель **`E171` (диоксид титана)** содержится в **14.8%** всех БАДов РФ, но сосредоточен в оболочках **твердых таблеток (31.5%)** и **непрозрачных капсул (14.4%)**. Сахар сконцентрирован в пастилках `Gummies` (**62.1%**) и шипучих таблетках (**32.0%**). |
| **H5** | **Есть ли разница, через какой аптечный агрегатор заказывать одни и те же витамины?** | Парный критерий `Friedman` + парный тест `Wilcoxon` ($N=129$ единых SKU) | $\chi^2_F = 36.11$<br>$p = 1.44 \times 10^{-8}$ | **Подтверждено:** на 129 идентичных товарах медианная цена на `Apteka.ru` (**951 ₽**) значимо ниже `Eapteka.ru` (**987 ₽**, $p = 2.96 \times 10^{-5}$) и `Zdravcity.ru` (**1105 ₽**, $p = 3.91 \times 10^{-14}$), а выбор лучшей сети через мета-агрегатор `Uteka.ru` (**781 ₽**) экономит **23.8%** от средней аптечной полки (**1208 ₽**). |

## 🖥️ Структура интерактивного дашборда (`app.py`)

Все 5 вкладок спроектированы в едином темном стиле **Dark BioTech Glassmorphism** с понятными русскоязычными подписями как для покупателей, так и для продакт-менеджеров и R&D-технологов:

1. **Вкладка 1 — `📡 1. Обзор рынка и рейтинг выгоды`:**
   - 5 выровненных KPI-индикаторов с пояснением простыми словами, как устроен индекс ценности `NVI` и чем отличаются уровни усвоения `Уровень 1–3`.
   - Переключатель между полноэкранной **«а) Картой позиционирования препаратов»** (с настройкой числа точек и контрастными зонами R&D-выгоды и маркетинговой переплаты) и **«б) Структурой рынка по категориям выгоды»**.
   - Полный интерактивный каталог всех **897 препаратов** с живым поиском, указанием производителя, страны, реальной цены дня и переплаты за бренд.
2. **Вкладка 2 — `🧮 2. Калькулятор честной цены и R&D-симулятор`:**
   - *Режим А (Проверка реального препарата из аптеки):* понятный паспорт препарата, водопадный график `SHAP` в рублях (*«Из чего складывается честная цена упаковки?»*) и сравнение цен в аптечных сетях (`Uteka.ru`, `Apteka.ru`, `Zdravcity.ru`, `Eapteka.ru`).
   - *Режим Б (Симулятор запуска нового БАДа):* расчет честной рыночной цены, цены 1 дня с учетом усвоения и ожидаемого индекса `NVI` при выборе категории, уровня формы и варианта чистоты состава.
3. **Вкладка 3 — `🧬 3. Разбор составов, форм и брендов`:**
   - Наглядные графики парадокса усвояемости (`Уровень 1 vs Уровень 2 vs Уровень 3`) и распределения диоксида титана `E171` и сахара по формам выпуска.
   - Русскоязычный рейтинг производителей по качеству формул, среднему индексу `NVI` и чистоте состава (`vw_brand_rnd_scorecard`).
4. **Вкладка 4 — `🎯 4. Поиск рыночных ниш для бизнеса`:**
   - Интерактивная тепловая карта `Категория витамина × Форма выпуска` с пояснением **«Индекса потенциала ниши»**.
   - Таблица **«Топ-12 самых перспективных свободных ниш («Голубые океаны»)»** (`vw_white_space_matrix`) с готовым бизнес-выводом по каждой нише.
5. **Вкладка 5 — `🧪 5. Стат. гипотезы и методология NVI`:**
   - Наглядное описание методологии `NVI` + интерактивный мини-симулятор выгоды.
   - 5 карточек проверенных гипотез (`H1–H5`) с явной формулировкой нулевой ($H_0$) и альтернативной ($H_1$) гипотез, таблицами выборок и практическими выводами, а также проводник аналитических SQL-витрин.

## 🚀 Быстрый запуск

### Локальный запуск (Python 3.10+)
```bash
git clone https://github.com/Erzor1/NutraMetrics.git
cd NutraMetrics
pip install -r requirements.txt

# (Опционально) Полный пересчет признаков, ML-модели, SQL-витрин, стат. тестов и Jupyter-ноутбука:
python src/feature_engineering.py
python src/pricing_model.py
python src/database.py
python src/hypothesis_testing.py

# Запуск веб-дашборда Streamlit на выделенном локальном порту 8502:
python -m streamlit run app.py --server.port 8502 --server.address 127.0.0.1
```

### Запуск в Docker
```bash
docker compose up -d --build
# Дашборд будет доступен по адресу: http://127.0.0.1:8502
```
