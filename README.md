**NutraMetrics** — это End-to-End аналитический продукт на живых данных аптечного рынка РФ (**907 пероральных препаратов** с кросс-агрегаторным покрытием `Uteka.ru`, `Apteka.ru`, `Zdravcity.ru`, `Eapteka.ru`, `Ригла`, `Планета Здоровья`), объединяющий **глубокую доменную экспертизу в R&D нутрицевтиков и фармацевтике** с **коммерческой и продуктовой аналитикой данных**.

> **О бэкграунде автора:**  
> Химик-исследователь (R&D) и аналитик данных с 6+ летним опытом разработки систем доставки биологически активных веществ в FoodTech/Nutraceutical-стартапе **«Nuversys» (Израиль)** (технологии микроинкапсуляции жирорастворимых витаминов D, E, A, K, Омега-3 и куркумина для внедрения в жевательные пастилки *Gummies*, протеиновые батончики и функциональные продукты) и разработки твердых лекарственных форм в **«Биннофарм Групп»**.

---

## 🎯 Бизнес-задача: зачем рынку нужен NutraMetrics?

На рынке БАДов и витаминов РФ существует фундаментальная асимметрия информации:
1. **Для потребителя:** Сравнение «цены за упаковку» или «цены за 1 таблетку» вводит в заблуждение. Банка оксида магния за 400 ₽ с приемом по 4 таблетки в день (курс 7.5 дней, биодоступность ~4–10%) в пересчете на усвоенную суточную дозу оказывается **дороже**, чем банка хелатного бисглицината или липосомальной формы за 700 ₽ на 60 дней.
2. **Для бизнеса (Category Managers аптек/маркетплейсов и R&D-директоров):** Необходимо понимать, какие бренды берут справедливую премию за сложную технологию доставки (`Tier 3: Липосомы / Мицеллы / Хелаты / Коферменты`), какие продают базовые неорганические соли с 200% маркетинговой наценкой, и в каких пересечениях `Категория вещества × Форма доставки` находятся **незанятые рыночные ниши (White-Space / Blue Ocean)** для запуска новых SKU.

## 🧪 Кастомная система метрик (R&D + Unit Economics)

### 1. Номинальная и эффективная стоимость суточной дозы ($C_{\text{day}}$ и $\text{BAP-Dose}$)

1. **Номинальная стоимость 1 дня курса ($C_{\text{day}}$, ₽/день):**
   $$C_{\text{day}} = \frac{\text{Price}_{\text{pack}}}{\text{Pack Servings} / \text{Daily Serving}}$$

2. **Коэффициент биодоступности и технологии доставки ($K_{\text{bio}}$ — экспертная R&D-классификация):**
   - **`Tier 1: Basic Inorganic` ($K_{\text{bio}} = 1.00$):** Неорганические соли минералов (оксиды, сульфаты, карбонаты, хлориды), нестандартизированный рыбий жир, синтетическая фолиевая кислота / цианокобаламин в базовых таблетках, советские сахарные драже (*Ревит, Ундевит, Гексавит*).
   - **`Tier 2: Organic / Enhanced` ($K_{\text{bio}} = 1.35$):** Органические соли минералов (цитраты, малаты, лактаты, глюконаты, пиколинаты, фумараты), мягкие желатиновые капсулы (*Softgels*), жидкие масляные капли, шипучие таблетки (*Effervescent*), жевательные мармеладные пастилки (*Gummies*), гидролизованные пептиды коллагена.
   - **`Tier 3: Advanced R&D Delivery Systems` ($K_{\text{bio}} = 1.75$):** Аминокислотные хелатные комплексы (**бисглицинат, таурат, L-треонат**), **липосомальные**, **мицеллированные**, **микроинкапсулированные / сукросомальные** матрицы, коферментные активные формы витаминов (**L-метилфолат, метилкобаламин, P-5-P**), куркумин с биоэнхансером **пиперином (BioPerine)**, высококонцентрированная триглицеридная **rTG Омега-3 (60–90%)**, трипептиды морского коллагена и синергические матрицы **D3 + K2 (MK-7)**.

3. **Фактор чистоты состава Clean Label ($K_{\text{clean}} \in [0.85, 1.15]$):**
   - **Штрафы:** за сахар / глюкозно-паточный сироп на первых местах состава (`-0.08`), **диоксид титана `E171`** в оболочках таблеток и капсул (`-0.07`), синтетические азокрасители и жесткие консерванты (`-0.05`).
   - **Бонусы:** за чистые носители (МСТ-масло среднецепочечных триглицеридов, оливковое масло Extra Virgin, растительные капсулы ГПМЦ/пуллулан, пребиотик инулин) и короткий перечень эксципиентов без `E171` и сахара (`+0.08..+0.12`).

4. **Эффективная биодоступная стоимость суточной дозы (`BAP-Dose`, ₽):**
   $$\text{BAP-Dose} = \frac{C_{\text{day}}}{K_{\text{bio}} \times K_{\text{clean}} \times D_{\text{factor}}}$$
   где $D_{\text{factor}} = \text{clip}\left(\sqrt{\frac{\text{Daily Active Dose}}{\text{Category Reference Dose}}}, 0.55, 1.75\right)$ учитывает полноту профилактической дозировки активного вещества.

5. **Индекс ценности нутрицевтика (`NVI`, 0–100 баллов внутри категории):**
   Агрегирует ценовую эффективность `BAP-Dose` (45%), технологический уровень формы доставки $K_{\text{bio}}$ (30%), чистоту состава $K_{\text{clean}}$ (15%) и байесовский сглаженный рейтинг доверия покупателей (10%).

---

### 2. Индекс маркетинговой переплаты — `Brand Overpay %` (Hedonic Pricing ML + SHAP)

Мы обучаем регрессионную модель гедонистического ценообразования (`CatBoostRegressor` на $\ln(\text{Price})$, $R^2 = 0.540$), используя **только фундаментальные R&D и галеновые признаки** (категория, длительность курса, адекватность дозировки, объем упаковки, `Bio-Tier`, галеновая форма, `Clean Label`, импорт/локализация) **без участия имени бренда**:
$$\text{Brand Overpay \%} = \frac{P_{\text{actual}} - P_{\text{fair}}}{P_{\text{fair}}} \times 100\%$$
- Точная аддитивная декомпозиция `SHAP Values` переводится в рубли (`shap_base_rub`, `shap_category_rub`, `shap_dosage_course_rub`, `shap_bio_tier_rub`, `shap_delivery_form_rub`, `shap_clean_label_rub`, `shap_origin_rub`), формируя интерактивный водопадный график (**SHAP Waterfall Chart**) для каждого из 907 препаратов и для симулятора запуска нового продукта.

## 📊 Ключевые статистически доказанные инсайты (`scipy.stats`, `statsmodels`)

На выборке из **907 пероральных нутрицевтиков** проверены 5 продуктовых и технологических гипотез (подробный код и выводы — в `notebooks/eda_and_hypotheses.ipynb` и `src/hypothesis_testing.py`):

| Код | Продуктовая / R&D гипотеза | Статистический критерий | Результат и p-value | Главный бизнес- и R&D-вывод |
| :--- | :--- | :--- | :--- | :--- |
| **H1** | **Парадокс биодоступности R&D Tier 3 vs Tier 1/2** | `Kruskal-Wallis H` + попарный `Mann-Whitney U` (поправка Холма–Бонферрони) | $H_{\text{NVI}} = 268.7$<br>$p = 4.41 \times 10^{-59}$<br>$\varepsilon^2 = 0.297$ | Номинально день приема `Tier 3` дороже `Tier 1` (**17.32 ₽** vs **11.27 ₽**), но в пересчете на усвоение эффективная стоимость **`BAP-Dose` у `Tier 3` минимальна на рынке — 9.14 ₽/день** (против **12.96 ₽** у `Tier 2`, $p_{\text{Holm}} = 3.56 \times 10^{-6}$). |
| **H2** | **Импортная премия при контроле технологии доставки** | Двухфакторный `Type-II OLS ANOVA` + `Mann-Whitney U` | $F = 228.6$<br>$p = 3.61 \times 10^{-46}$ | При фиксированном `Bio-Tier` и категории вещества импортные БАДы несут чистую наценку **+122.2%** (медиана **1050 ₽** vs **486 ₽** у РФ). Локальные R&D-бренды с хелатами и липосомами выигрывают по среднему `NVI` (**62.4** vs **45.2**). |
| **H3** | **Unit-экономика галеновых форм (`Gummies` и `Липосомы`)** | `Kruskal-Wallis H` + Bootstrap 95% ДИ медианы | $H = 26.9$<br>$p = 6.25 \times 10^{-6}$ | Липосомальные/мицеллированные формы стоят **33.20 ₽/день**, а жевательные пастилки `Gummies` (**11.16 ₽/день**) сопоставимы с таблетками (**12.37 ₽/день**), но в **62.1%** случаев перегружены сахаром/патокой. |
| **H4** | **Поляризация эксципиентов: Диоксид титана (`E171`) и Сахар** | $\chi^2$ Пирсона + $V$ Крамера + точный тест Фишера | $\chi^2_{\text{E171}} = 81.8$ ($p = 5.8 \times 10^{-15}$)<br>$\chi^2_{\text{Sugar}} = 255.8$ ($p = 1.6 \times 10^{-51}$) | Запрещенный в ЕС пищевой краситель **`E171` (диоксид титана)** сосредоточен в пленочных оболочках твердых таблеток (**31.1%**) и капсул (**14.3%**). Сахар сосредоточен в `Gummies` (**62.1%**) и шипучих формах (**32.0%**). |
| **H5** | **Ценовой арбитраж между аптечными агрегаторами** | Парный критерий `Friedman` + парный тест `Wilcoxon` ($N=138$ полных пар) | $\chi^2_F = 24.8$<br>$p = 4.04 \times 10^{-6}$ | Медианная цена идентичных SKU на `Apteka.ru` (**935 ₽**) значимо ниже `Eapteka.ru` (**961 ₽**, $p = 2.7 \times 10^{-5}$) и `Zdravcity.ru` (**1064 ₽**, $p = 2.5 \times 10^{-13}$), а выбор лучшей аптеки через `Uteka.ru` (**751 ₽**) экономит **23.8%** от средней аптечной полки. |

## 🖥️ Структура интерактивного дашборда (`app.py`)

1. **Tab 1 — `📡 Market Radar & Unit Economics`:** KPI-карточки в стиле Glassmorphism, интерактивная карта позиционирования `Scatter Plot` ($C_{\text{day}}$ vs `NVI`), распределение по 6 рыночным квадрантам и таблица лидеров с фильтрацией по источникам (`Uteka.ru`, `Apteka.ru`, `Zdravcity.ru`, `Eapteka.ru`).
2. **Tab 2 — `🧮 Калькулятор Честной Цены (ML + SHAP)`:**
   - *Режим А:* SHAP-аудит любого из 907 реальных препаратов с водопадным графиком в рублях и сравнением цен в аптечных сетях.
   - *Режим Б (R&D Simulator):* Живой расчет справедливой цены $P_{\text{fair}}$, `BAP-Dose` и `Brand Overpay %` для проектирования нового БАДа.
3. **Tab 3 — `🧬 Химико-технологический разбор (R&D)`:** Визуализация парадокса биодоступности (`Tier 1 vs Tier 2 vs Tier 3`), аудит диоксида титана `E171` и сахара по галеновым формам и рейтинг производителей (`vw_brand_rnd_scorecard`).
4. **Tab 4 — `🎯 Матрица рыночных ниш (White-Space)`:** Тепловая карта `Категория вещества × Форма доставки` и ранжированный список **Blue Ocean R&D-ниш** (`vw_white_space_matrix`).
5. **Tab 5 — `📐 Стат. гипотезы & SQL-витрины`:** Результаты стат. тестов `H1–H5` и встроенный интерактивный SQL-движок для выполнения произвольных запросов к `data/nutrametrics.db`.

## 🚀 Быстрый запуск

### Локальный запуск (Python 3.10+)
```bash
git clone https://github.com/Erzor1/NutraMetrics.git
cd NutraMetrics
pip install -r requirements.txt

# (Опционально) Пересчет признаков, ML-модели, SQL-витрин и стат. тестов:
python src/feature_engineering.py
python src/pricing_model.py
python src/database.py
python src/hypothesis_testing.py

# Запуск веб-дашборда Streamlit (Dark Mode):
streamlit run app.py
```

### Запуск в Docker
```bash
docker compose up -d --build
# Дашборд будет доступен по адресу: http://localhost:8501
```
